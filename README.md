# 钥匙柜借还与班次交接（车辆调度小工具扩展）

- 行业：物流
- 技术栈：Vue3、Vite、TypeScript、Pinia（无新增依赖）
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

在原车辆调度小工具基础上扩展出钥匙柜借还与班次交接口，数据默认保存在浏览器 localStorage，刷新后钥匙状态、借还记录、占用关系与换锁版本保持一致。

## 目录分层

| 层 | 路径 | 职责 |
| --- | --- | --- |
| 数据 | `src/data/types.ts`、`src/data/seed.ts` | 领域模型、状态枚举、种子数据、存储键与版本号 |
| 规则 | `src/rules/keyRules.ts` | 纯函数：借还约束、里程油量校验、占钥推导、班次重叠、逐柜交接核对 |
| 存储 | `src/storage/localStore.ts` | localStorage 读写与结构兜底，不含业务规则 |
| 状态 | `src/stores/keyCabinet.ts` | Pinia store，写操作先过规则再落库 |
| 页面 | `src/App.vue`、`src/components/*.vue` | 钥匙柜总览、借出登记、借还记录、班次交接、换锁记录 |

## 业务规则

- **借出登记**：按车牌、司机、班次、起始里程登记；同车未归还（含待复核）前不得再借；同司机在重叠班次（含交接班重叠时段）只能持一把。
- **归还登记**：须录结束里程、油量、车况并核对归还柜位。缺项、里程倒挂（结束里程小于起始里程）、油量低于三成（<30%）时停在「待复核」，复核前仍占钥匙；复核通过才归还入柜。
- **班次交接**：逐柜核对，钥匙遗漏（含其他班次未还、待复核未结）、归还柜位错位、车辆任务未结束均列为阻塞项，展示车牌、柜位、司机和阻塞原因；存在任一项不能关班。
- **丢失与换锁**：钥匙丢失只能新建带原因的换锁记录，钥匙版本 +1；旧借还链完整保留，旧版本不再占用钥匙，新钥匙可正常借出。
- **一致性**：所有写操作即时落库，钥匙状态与占用均由借还链 + 当前钥匙版本推导，不做独立冗余存储。

## 班次时间（用于重叠判定，晚班跨天）

- 早班 06:00–14:00，中班 13:00–22:00，晚班 21:00–次日 07:00（相邻班次含 1 小时交接重叠）

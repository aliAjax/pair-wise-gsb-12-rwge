# 车辆调度 · 钥匙柜借还与班次交接

- 行业：物流
- 技术栈：Vue3、Vite、TypeScript（无新增依赖，数据保存在浏览器 localStorage）
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

## 功能闭环

### 1. 钥匙借出
- 按 **车牌、司机、班次、起始里程（+班次日期）** 登记借钥。
- **同车未归还前不得再借**：存在“借出/待复核”借还单时拦截。
- **同司机重叠班次只能持一把**：按各班次起止时间判断区间重叠，晚班跨午夜自动顺延。

### 2. 钥匙归还与待复核
- 归还须录 **结束里程、油量（%）、车况**。
- **缺项、里程倒挂（结束里程 < 起始里程）、油量低于三成（<30%）** 任一命中，单据停在“待复核”，并记录具体原因。
- **复核前仍占钥匙**：车辆不能再借、柜位仍显示在司机手中；复核员补录/修正后通过即归还入柜。

### 3. 班次交接（逐柜核对）
- 每个柜位按实盘选择在柜车牌（或空柜）。
- 阻塞条件：**钥匙遗漏**（应在柜却为空）、**钥匙错位**（柜内车牌不符/同车出现在多柜）、**车辆任务未结束**（执行中）、仍有未终结借还单（含待复核）。
- 阻塞列表明确给出 **车牌、柜位、司机、阻塞原因**；存在阻塞时“确认关班”按钮禁用，关班后保存核对快照。

### 4. 丢失换锁
- 丢失不允许删除或改写历史：只能 **新建带原因的换锁记录**，旧借还链完整保留。
- 换锁后该车牌钥匙 **版本递增**（v1 → v2 …），新钥匙入柜（校验目标柜位未被占用），原借还单仅终结并关联换锁单。

### 5. 一致性与本地存储
- 柜位占用、钥匙位置、换锁版本均由借还链/换锁记录 **派生**，刷新后自动一致。
- 每次变更递增 `rev`，并通过 `storage` 事件同步其它标签页。
- 刷新后执行一致性自检：同车多重占用、版本倒挂、换锁链断裂、柜位双钥匙、待复核无原因、引用缺失等，在页首红条列出。

### 6. 车辆调度（保留原能力）
- 车辆/司机维护、配送任务分配与状态流转（空闲 → 执行中 → 已完成），执行中的任务同时是交接阻塞项。

## 代码分层（数据 / 规则 / 存储 / 页面分开，互不越界）

| 文件 | 职责 | 是否依赖 Vue/浏览器 |
| --- | --- | --- |
| `src/types.ts` | 数据模型 | 否 |
| `src/schema.ts` | 初始演示数据、常量 | 否 |
| `src/rules.ts` | 全部业务规则：借还校验、班次区间、占用派生、交接核对、一致性自检（纯函数） | 否 |
| `src/storage.ts` | localStorage 读写、跨标签页订阅 | 仅浏览器 API（带 SSR 防御） |
| `src/store.ts` | 用 Vue `reactive` 组合上面三层，提供操作接口 | Vue |
| `src/components/*.vue`、`src/App.vue` | 页面 | Vue |
